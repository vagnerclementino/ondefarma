# Prompt de Favicon (Gemini) - Versao Alinhada ao Projeto

```text
Create a favicon for the web app "Ache uma Farmacia Popular".

Product context:
This app works like a lightweight "Google Maps for Farmacia Popular" in Brazil:
it helps users find accredited pharmacies by location (state, city, neighborhood).
The icon must communicate: location + pharmacy + public-service trust.

Core concept (mandatory):
Design one unified symbol that merges:
1) a map pin (localizacao)
2) a pharmacy cue (cross or capsule)
Use an integrated shape, not separate clip-art elements.

Visual direction:
Minimal, civic, practical, trustworthy, friendly.
Flat vector, geometric construction, strong silhouette.
No text, no initials, no coat of arms, no government seal.

Brand/system colors (strict priority):
- Primary blue: #0847AA or #0B4AA8
- Light support blue: #E9F3FF
- White: #FFFFFF
- Optional dark neutral: #111111
High contrast only.

Favicon readability rules:
- Must remain clear at 16x16 and 32x32.
- Thick strokes, simplified internal cutouts.
- Symmetrical or near-symmetrical composition.
- Avoid micro-details and visual noise.

Output request:
Generate 4 clean variants:
1) Transparent background
2) Blue background + white symbol
3) White background + blue symbol
4) Rounded-square tile style
Export as crisp SVG-ready vector style.

Negative constraints:
No 3D
No photorealism
No mockups
No long shadows
No complex gradients
No clutter
No tiny details
```

Complemento opcional para reforcar o contexto no Gemini:

```text
Prioritize "finding nearby pharmacy" over "medicine only". The map-pin meaning should be instantly recognizable before the pharmacy detail.
```
